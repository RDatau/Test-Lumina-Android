# Lumina AI - Android App

Lumina AI adalah aplikasi asisten AI cerdas dan teman ngobrol fleksibel yang kini hadir dalam bentuk aplikasi natif Android menggunakan Kotlin dan Jetpack Compose.

## Fitur Utama
- **Pilihan Karakter AI**: Berinteraksi dengan berbagai karakter AI unik (Lumina, Luna, Aris) dengan kepribadian masing-masing.
- **Obrolan Real-time**: Kirim pesan dan dapatkan respons cerdas yang ditenagai oleh Gemini API.
- **Panggilan Suara**: Simulasi panggilan suara interaktif dengan tampilan yang elegan.
- **Wizard Karakter**: Buat atau sesuaikan karakter AI kustom sesuai keinginan Anda.
- **Pengaturan & Profil**: Kelola kunci API Gemini, model pilihan, dan profil pengguna dengan mudah.

## Dibangun Dengan
- **Kotlin** & **Jetpack Compose** (Material Design 3)
- **OkHttp** & **Gson** untuk komunikasi Gemini API
- **Coil** untuk pemuatan gambar asinkron
